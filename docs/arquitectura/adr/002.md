## 1. Contexto y Declaración del Problema

Se decidió utilizar Kong API Gateway como solución estándar para la plataforma, para la implementación de enrutamiento dinámico y balanceo de carga entre el monolito y los microservicios, centraliza la autenticación/autorización con plugins de OAuth2, OpenID Connect (OIDC) y JWT; y podrán Aplicar políticas de Rate Limiting, CORS, Throttling y registros de auditoría en la capa de borde. 

---

## 2. Opciones Consideradas

Enumere las alternativas técnicas o de arquitectura evaluadas para resolver el problema:

* **Opción 1:** Kong API Gateway

## 3. Decisión Tomada

Decidimos seleccionar la **Kong API Gateway** porque permite la implementación de enrutamiento dinamico y balanceo de carga entre el monolito y los microservicios.
